## Avant la démo (2 min)

```bash
cd ops-gate
pnpm build
```

1. Chrome → `chrome://extensions` → recharger **OpsGate** depuis `build/chrome-mv3-prod`
2. Ouvrir **https://chatgpt.com** (ou Claude) en navigation normale
3. Vérifier le **badge cyan** en bas à droite
4. Popup OpsGate : statut **Actif**, journal éventuellement vidé

## Message clé (à retenir)

> *« Utilisez l’IA librement. Protégez vos données automatiquement. »*  
> OpsGate n’est **pas** un bloqueur : il **alerte**, **propose le masquage**, et laisse le choix.  
> Tout reste **local** dans le navigateur.

## Secrets de démo

Les échantillons sont **volontairement factices**. Ne jamais coller de vrais secrets pendant une démo.
